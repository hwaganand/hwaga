# Suno 라이브러리 WAV 일괄 다운로드

## 이 스킬이 하는 일

suno.com에서 생성한 곡들을 WAV로 자동 다운로드한다. Suno UI는 다중 선택 ZIP 다운로드에서 WAV를 막아놨기 때문에("WAV available for single songs only"), 곡을 하나씩 순회하며 개별 다운로드하는 방식만 가능하다.

## 시작 전 반드시 확인할 것

1. **플랜**: WAV는 Pro/Premier 플랜 전용. Free/Basic 플랜은 MP3만 가능하므로 이 스킬을 실행해도 실패한다. 사용자에게 플랜을 먼저 물어볼 것.
2. **실행 위치**: 반드시 **사용자의 로컬 PC**에서 실행해야 한다. 원격/클라우드 세션에는 사용자의 Suno 로그인 세션이 없어서 로그인 화면에서 막힌다.
   - 원격 세션에서 요청받았다면: 스크립트 파일을 사용자에게 전달하고, 로컬 Claude Code나 터미널에서 실행하도록 안내할 것.
   - 사용자가 "쿠키 넘겨줄 테니 네가 원격에서 돌려라"라고 하면, 쿠키 = 로그인 토큰이라는 리스크를 먼저 명확히 알린 뒤 동의를 받고 진행할 것.
3. **소요 시간**: WAV는 곡마다 서버에서 새로 인코딩되므로 곡당 수 초~수십 초 걸린다. 수백 곡이면 몇 시간 단위다. 사용자에게 미리 알릴 것.

## 실행 절차

```bash
pip install playwright
playwright install chromium
python .claude/skills/suno-wav-download/suno_wav_downloader.py
```

1. 크롬 창이 뜨면 **사용자가 직접** Suno에 로그인한다 (비밀번호를 스크립트나 대화에 절대 입력받지 않는다).
2. 라이브러리 페이지로 이동한 뒤 터미널에서 Enter.
3. 스크립트가 전체 스크롤로 곡 목록을 수집하고 한 곡씩 WAV를 받는다.
4. 저장 위치: `~/Downloads/suno_wav/`
5. 로그인 세션은 `~/.suno_downloader_profile`에 저장되어 다음 실행부터는 로그인 불필요.

## 중간에 끊겼을 때

같은 명령을 다시 실행하면 된다. 이미 받은 파일명은 건너뛰므로 이어받기가 된다.

## 셀렉터가 안 맞을 때 (가장 흔한 실패)

Suno는 UI를 자주 바꾸고 클래스명이 난독화되어 있어서, "곡 0개 발견" 또는 타임아웃 실패가 뜨는 경우가 많다. 이때 대응 순서:

1. `HEADLESS = False` 상태로 실행해 브라우저에서 어디서 멈추는지 눈으로 확인한다.
2. F12 → 곡 행(row)을 검사(Inspect)해서 실제 속성을 확인한다.
3. `suno_wav_downloader.py`의 `collect_song_rows()`에 있는 셀렉터 문자열을 실제 값으로 교체한다.
4. `⋯` 버튼이 안 잡히면 `download_wav_for_row()`의 `get_by_role("button", name=...)` 부분을 실제 aria-label 기준으로 수정한다.

DOM 구조를 추측으로 채우지 말고, 반드시 사용자가 확인한 실제 값으로 고칠 것.

## 주의

- 다운로드를 너무 빠르게 반복하면 레이트리밋이나 계정 플래그 위험이 있다. `DELAY_RANGE` 기본값(4~9초)을 임의로 줄이지 말 것.
- 다운로드 횟수는 플랜별 쿼터에 카운트된다. 실행 전 사용자에게 곡 수를 알리고 진행 여부를 확인할 것.
