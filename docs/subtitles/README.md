# 자막 — 한글 / 영어

> 캡컷(CapCut) 작업용
> 번역은 사람이 다듬은 것이다. **자동번역을 쓰지 말 것.**

---

## 0. 왜 자동번역을 쓰면 안 되는가

이 대본은 말장난과 반복 대사로 짜여 있다. 기계번역은 그걸 다 놓친다.

| 대사 | 자동번역 | 이 문서 |
|---|---|---|
| 망했다 | It failed / I'm ruined | **I'm done for** |
| …아니 그걸 왜 알아 | Why do you know that | **…How does he even know that** |
| 이건 좀 느끼한데 | This is greasy | **…Way too cheesy** |
| 같이 할까요 | Shall we do it together | **…Together, then?** |

⚠️ **`망했다`는 1화 컷 7과 2화 컷 4에 두 번 나온다. 영어도 반드시 같은 문장이어야 한다.**
이 반복이 회수 장치다. 다르게 번역하면 장치가 사라진다.

같은 이유로 아래 대사들도 **양쪽 화에서 동일하게** 유지한다.

| 한글 | 영어 | 등장 |
|---|---|---|
| 망했다 | I'm done for | 1화 컷7 · 2화 컷4 |
| 넥타이 | tie | 1화 컷2·3·4·10 · 2화 컷1 |
| 예의상 | out of politeness | 2화 컷0·1 |

---

## 1. 캡컷 작업 순서 (권장)

1. 영상 편집을 끝내고 타임라인을 확정한다
2. **캡컷 자동 자막**으로 한글 자막을 뽑는다 → **타이밍만 쓴다**
3. 자동 인식된 한글을 이 문서의 대사로 **하나씩 교체한다** (오타·조사 오류가 많다)
4. 자막 트랙을 복제한다
5. 복제 트랙의 텍스트를 이 문서의 영어로 교체한다
6. 영어 트랙을 한글 아래에 배치, 폰트 크기 70~80%

**또는** 이 폴더의 `.srt` 파일을 불러와서 타이밍만 드래그로 맞춘다.

## 2. 자막 규칙

| 항목 | 값 |
|---|---|
| 한글 폰트 크기 | 화면 높이의 4.5% 이상 (하객석 뒤에서 읽혀야 한다) |
| 영어 폰트 크기 | 한글의 70~80% |
| 한 줄 최대 | 한글 20자 / 영어 42자 |
| 최대 2줄 | 3줄 넘으면 컷을 나눈다 |
| 노출 시간 | 글자 수 × 0.15초 이상 |
| 위치 | 하단 중앙, 한글 위 / 영어 아래 |

⚠️ **화면 안 텍스트(카톡·검색어)는 자막이 아니다.**
영상에 이미 한글로 박혀 있으므로, 영어는 **별도 자막으로 화면 상단에** 넣는다.
하단 대사 자막과 겹치지 않게 한다.
