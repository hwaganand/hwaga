# 캐릭터 레퍼런스 시트 — 신랑(남자 주인공) 「민준」

> 식전영상 《세 번째 만남》 재현 컷용 캐릭터 일관성 레퍼런스
> 산출물: 이미지 3장 (전신 3분할 / 표정 4분할 / 얼굴 턴어라운드 4분할)
> **버전 2 — 사용자 제공 K드라마 남주 프롬프트 기반 얼굴로 확정**

## 0. 캐릭터 설정

| 항목 | 내용 |
|---|---|
| 이름 | 민준 (신랑 역) |
| 나이대 | 20대 중반 |
| 스타일 | **현대식(모던)** — 사극/시대극 아님 |
| 직업 | 회사원 (사무직) |
| 성격 | 말주변 없음, 표현 서툼, 행동으로 하는 사람 |
| 비주얼 키워드 | **"잘생겼는데 긴장해서 뻣뻣한 남자"** |

얼굴은 K드라마 남주 톤으로 잘생기게 가되, **자세는 경직**시킨다. 이 갭이 로맨틱 코미디의 웃음 포인트다.
프롬프트에 `slightly stiff posture with tensed shoulders`를 고정으로 넣는 이유.

## 1. 레퍼런스 시트에서 **반드시 걷어내야 할** 연출 요소

원본 포스터용 프롬프트에는 아래가 들어 있었다. 시트에는 전부 **금지**다.

| 걷어낼 것 | 이유 |
|---|---|
| 골든아워 역광 / 앰버 림라이트 | 얼굴 절반이 그늘·색조에 먹혀서 정체성이 매번 달라진다 |
| 얕은 심도(f/1.4) / 크리미 보케 | 의상·실루엣이 뭉개져 레퍼런스 기능을 잃는다 |
| 85mm 인물 렌즈 압축 | 전신 패널에서 비율이 왜곡된다 |
| 머리카락 날림 | 헤어 실루엣이 장마다 바뀌어 일관성이 깨진다 |
| 시네마틱 컬러 그레이딩 | 피부톤 기준값이 사라진다 |

**시트는 무조건 평평한 중립 조명 + 전체 초점.**
감성 조명은 나중에 실제 재현 컷을 뽑을 때 다시 얹으면 된다. 시트는 '설계도'지 '작품'이 아니다.

## 8. 생성 팁

- **사진1을 먼저 확정하고, 그 결과 이미지를 사진2·3의 레퍼런스로 재투입**한다. 텍스트만으로 세 장을 따로 뽑으면 얼굴이 반드시 흔들린다.
