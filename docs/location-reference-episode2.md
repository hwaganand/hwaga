# 장소 레퍼런스 시트 — 2화 「남친룩」

> 캐릭터 레퍼런스와 같은 목적. **같은 장소가 여러 컷에 걸쳐 나오는데
> 텍스트 묘사만으로 매번 따로 생성하면 인테리어·조명·가구 배치가 컷마다 달라진다.**
> 여기 적힌 고정값을 해당 장소가 나오는 모든 컷 프롬프트에 그대로 반복해서 넣는다.

⚠️ **이탈리안 레스토랑은 플레이트가 확정됐다** (media `fa52480b-47b0-4427-a5be-afeb2fd7f7c7`,
사용자 제공 사진). 나머지 장소는 아직 텍스트 고정값뿐이다.
빈 공간 플레이트(인물 없이 배경만)를 `image_references`로 걸면 드리프트가
더 줄어드는데, 생성이 필요한 나머지 장소는 **생성 전 프롬프트를 사용자에게
먼저 보여주고 승인받은 뒤** 진행한다(프로젝트 규칙 4).

## 1. 남성복 매장 ★★★

컷 1(전반)·2·4·5·7(전반)에서 반복. **워크인 전신(컷 2), 여성 코너 표지판(컷 4),
니트 던지기(컷 5)가 모두 같은 공간 안에서 일어나야 한다.**

| 항목 | 고정값 |
|---|---|
| 규모 | 중소형 남성복 편집숍. 넓지 않다 — 두 사람이 옷걸이 하나 사이에 두고 대화 가능한 거리 |
| 조명 | 위에서 떨어지는 뉴트럴 화이트 스팟 조명 (트랙 조명), 매장 특유의 밝고 평평한 조도 |
| 벽/바닥 | 옅은 우드톤 바닥, 화이트/라이트그레이 벽 |
| 옷걸이 랙 | 원형 스틸 행거 2~3개, 옷이 색상별로 걸려 있다 (전경에 아웃포커스로 걸쳐도 됨) |
| 여성 코너 표지판 | ★ 컷 4에 필요 — 벽 부착형 작은 안내판 "WOMEN" 또는 여성 실루엣 아이콘, 니트 코너 위쪽 |
| 피팅룸 | 매장 안쪽에 커튼형 피팅룸 실루엣만 (전면에 안 나옴) |
| 계산대 | 프레임에 잡지 않는다 — 전 컷이 매대 사이 공간에서만 벌어진다 |
| 카메라 기준선 | 인물 허리 위 사이즈 기준. 배경에 행거 상단이 프레임 위쪽 1/3 안에 걸린다 |
| 색감 | LOOK 공통 규칙(약간 채도 낮춘 쿨톤) 유지, 단 조명 자체는 매장답게 밝게 |

⚠️ 컷 2는 **문(입구)이 프레임에 잡혀야 한다** — 민준이 문을 열고 들어오는 워크인.
문은 통유리 자동문 또는 손잡이형 유리문, 매장 로고 없음(가상 브랜드 특정 금지).

⚠️ 남성 캐주얼 편집숍이라는 인상만 주면 되고, 실존 브랜드 로고·간판 텍스트는
프롬프트에 절대 넣지 않는다(저작권).

## 2. 서연의 방 ★★★

컷 0·1(후반)·3·6·14에서 반복. **침대 위치, 거울 위치, 옷장 위치가 매번 같아야
컷 3의 "침대 위 옷더미"와 컷 6의 "거울 앞"이 같은 방으로 읽힌다.**

| 항목 | 고정값 |
|---|---|
| 구조 | 원룸 또는 자취방 침실. 아늑하고 좁은 개인 공간 |
| 침대 | 프레임 왼쪽, 헤드보드는 벽에 붙어 있다. 화이트/아이보리 침구 |
| 거울 | 프레임 오른쪽, 전신 거울 (스탠딩형), 옷장 문 옆에 배치 |
| 옷장 | 거울과 같은 벽면, 오픈형 또는 슬라이딩 도어. 지원이 뒤지는 동선 확보 |
| 조명 (낮/컷 3·6) | 창문에서 들어오는 자연광, 부드러운 확산광, 커튼은 화이트 시어 |
| 조명 (밤/컷 0·14) | 스탠드 조명 하나만 켜진 어두운 방, 폰 화면 빛이 얼굴에 반사 |
| 벽 | 뉴트럴 아이보리/베이지, 장식 최소 (사진 액자 1~2개 정도만 허용) |
| 바닥 | 라이트 우드 또는 러그 |
| 카메라 기준선 | 컷 0·14는 침대에 앉은/누운 인물 + 폰 화면 세로 배치. 컷 3·6은 거울 앞 입식 |

⚠️ 컷 0과 컷 14는 **같은 구도**여야 한다(1화 컷 10과도 연결). 스탠드 조명 위치,
침대에서 폰을 보는 각도를 두 컷 다 동일하게 고정한다.

⚠️ 컷 6 거울 앞 장면은 **거울에 서연의 얼굴이 반사되어 보여야** 컷 설계(립을
거울로 확인)가 성립한다.

## 3. 이탈리안 레스토랑 ✅ 확정

컷 8·9A·9B·10A·10B, 전부 **같은 테이블, 같은 자리 배치**여야 한다. 민준과 서연은
매 컷 같은 쪽에 앉는다(교차 편집이 아니라 한 자리에서 이어지는 장면이므로 특히 중요).

**확정 플레이트**: media `fa52480b-47b0-4427-a5be-afeb2fd7f7c7` (사용자 제공 사진 —
2인 원형 테이블, 화이트 테이블보, 메뉴판, 캔들, 물잔 2개, 구리색 펜던트 조명,
창밖 야경. 아래 고정값과 정확히 일치한다). 이 장소가 나오는 모든 컷에
`image_references`로 같이 건다. 인물이 없는 빈 공간 사진이라 캐릭터
레퍼런스와 충돌하지 않는다.

| 항목 | 고정값 |
|---|---|
| 규모 | 작은 이탈리안 레스토랑, 테이블 간격이 좁아 아늑하다 |
| 테이블 | 2인용 스몰 테이블, 화이트 테이블보, 이 테이블 하나에서 8~10 전부 진행 |
| 자리 배치 | 민준 프레임 기준 오른쪽, 서연 프레임 기준 왼쪽에 앉는다 (고정) |
| 조명 | ★ 따뜻한 펜던트 조명 (테이블 위에 낮게 걸림), 그레이딩은 쿨하게 — 조명은 웜, 색보정은 쿨 |
| 소품 | 물잔 2개(컷 8에서 중요 — 서버가 따르는 잔), 메뉴판, 식기, 작은 캔들 |
| 배경 | 아웃포커스로 다른 테이블 실루엣, 벽에 옅은 조명 소스 몇 개 |
| 창문 | 있다면 밤 거리 불빛이 배경에 흐릿하게 (컷 11로 이어지는 톤 연결) |
| 카메라 기준선 | 투샷 없음. 가슴 위 단독 샷, 상대는 어깨 너머로만 살짝 |

⚠️ 컷 8의 물잔은 **서버가 따르는 순간과 다시 빈 상태가 화면에 다 나와야** 개그가
성립한다 — 잔 위치를 프레임 안 고정된 자리에 둔다.

⚠️ 이 화 유일하게 웜톤 조명을 쓰는 장소다. 단, 3화 손 잡는 순간의 웜톤 전환과
겹치지 않도록 **그레이딩 자체는 쿨하게 눌러둔다** (조명 소스만 웜, 필름룩은 쿨).

## 4. 서연의 집 현관 ★

컷 7(후반) 단독 등장. 방과 같은 집이지만 다른 세트 — 방을 나가는 동선의 끝.

| 항목 | 고정값 |
|---|---|
| 구조 | 좁은 현관. 신발장, 도어 하나 |
| 도어 | 화이트 또는 우드톤 현관문, 안쪽에서 밀려 나가는 구도 |
| 조명 | 방보다 약간 어둡고 차가운 톤 (복도 감지등 느낌) |
| 카메라 기준선 | 컷 7 매치컷 규칙 그대로 — 옷가게 문과 **같은 사이즈·같은 앵글** |

⚠️ 옷가게(장소 1)의 출입문과 **프레임 구성(인물 크기, 손이 등에 닿는 위치)이
동일해야** 매치컷이 성립한다. 두 문의 생김새(재질·색)는 달라도 되지만 카메라
사이즈는 반드시 맞춘다.

## 5. 밤거리 / 횡단보도 ★

컷 11 단독. 무대사 컷이라 장소 자체의 톤이 대사를 대신한다.

| 항목 | 고정값 |
|---|---|
| 거리 | 도심 인도, 왕복 2차선 정도의 횡단보도 |
| 신호등 | 프레임 위쪽에 걸리는 위치 (하이앵글 숏 1의 기준) |
| 조명 | 가로등 + 신호등 불빛, 쿨톤 유지. 레스토랑의 웜톤과 대비 |
| 인도 | 세로로 길게 뻗어야 한다 — 6)번 숏(민준이 차도 가장자리로 걷는 것)이 세로 프레임에서 읽히려면 인도 방향이 카메라를 향해 뻗어 있어야 함 |
| 배경 | 야간 도시 실루엣, 지나가는 차 1~2대 정도 (과하지 않게) |

## 6. 인터뷰 백드롭 (2종) ★★

컷 12·13. 실제 "장소"라기보다 촬영 세트 컨벤션 — 1화 인터뷰와 같은 계열로
**뉴트럴 배경 + 균일한 소프트 조명**만 있으면 된다. 두 자리를 명확히 구분한다.

| | 준영 자리 | 서연·지원 자리 |
|---|---|---|
| 벽 | 회색(그레이) 심리스 배경 | 아이보리 심리스 배경 |
| 조명 방향 | 한쪽에서 살짝 치우친 소프트광 | 반대쪽에서 치우친 소프트광 — 준영 자리와 명확히 구분 |
| 프레임 | 가슴 위 사이즈, 고정 카메라 | 서연 단독은 준영과 동일 사이즈. 서연+지원 투샷은 지원이 뒤쪽에서 앞으로 기울여 프레임 위쪽에 들어옴 |
| 공통 | 근접 마이크, 배경에 소품 없음(순수 세미리스 컨벤션) | 좌동 |

⚠️ 컷 13(서연 단독, 인정 컷)은 **컷 12의 서연 프레임과 완전히 동일**해야 한다 —
같은 벽, 같은 조명, 같은 사이즈. 카메라가 전혀 움직이지 않는 게 규칙이다.
