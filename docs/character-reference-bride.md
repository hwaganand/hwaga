## 3. 세트 고정 (기준 이미지와 동일하게)

| 항목 | 확정값 |
|---|---|
| 배경 | **웜 베이지** 심리스 스튜디오 (신랑과 통일) |

| 신발 | **화이트 로우탑 스니커즈** |
| 앞머리 | **에어리 시스루 뱅** (숱 있는 일자 뱅 아님) |
| 액세서리 | 작은 진주 스터드 귀걸이 |

### 신랑과 세트가 맞춰져 있다

| | 신랑 (base) | 신부 |
|---|---|---|
| 배경 | 웜 베이지 | 웜 베이지 |
| 조명 | 웜 확산광 | 웜 확산광 |
| 상의 | 아이보리 포플린 셔츠 | 크림 아이보리 니트 가디건 |
| 하의 | 블랙 테일러드 슬랙스 | 블랙 스키니진 |
| 신발 | 블랙 더비 | 화이트 스니커즈 |

**상의 아이보리 / 하의 블랙**이 두 사람 모두 동일하다. 투샷이 바로 된다.
신발만 다르지만 시트에서 문제되지 않는다 — 씬에서는 어차피 갈아신는다.

#### 여기까지 온 경위 (같은 실수 반복 방지)

처음엔 신부가 어려 보이는 원인을 **스커트 길이**로 봤다. 틀렸다.
미디 스커트 + 가디건 + 로퍼로 갔더니 나이는 올라갔지만 촌스러워졌다.

실제 원인은 **신발과 앞머리**였다.
- 미니스커트 + 스니커즈 + 일자뱅 = 교복
- 미니스커트 + 로퍼 + 시스루뱅 = 20대 중반

최종적으로 스커트를 아예 **블랙 테일러드 슬랙스**로 바꾸면서 해결됐다.
남자가 같은 블랙 슬랙스를 입고 있어서 커플 룩이 정확히 맞아떨어진다.

## 7. 생성 팁

- 여성 캐릭터는 **앞머리와 눈매**에서 정체성이 무너진다. 표정을 세게 쓸수록 눈이 딴사람이 되니, 표정 묘사는 약하게 쓰는 편이 안전하다.
- 4번 표정(눈물 고인 미소)이 제일 위험하다. 깨지면 "눈가가 살짝 붉어진 미소" 정도로 낮춰서 다시 뽑는다.
- 턴어라운드의 후면 패널은 긴 생머리라 신랑보다 잘 나오는 편이다. 대신 **머리 길이가 패널마다 달라지는지** 확인할 것.
