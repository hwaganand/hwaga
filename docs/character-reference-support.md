## 1. 1:1 대칭 구조 ★

**남자 조연을 준영 한 명으로 줄였다.** 태호는 폐기.

| | 지원 | 준영 |
|---|---|---|
| 짝 | 서연 | 민준 |
| 역할 | 방자·향단 포지션 — 주인공의 헛짓을 정확히 찌른다 |
| 웃음 만드는 법 | **말로 찌른다** | **얼굴이 무너진다** |
| 대사량 | 많다 | 적다 |
| 음역대 | 고음 | 중음 |

**역할은 같고 온도만 반대다.** 크로스컷할 때 음역대가 매 컷 교대로 튀어서
편집 리듬이 저절로 생긴다.

### 3샷을 2샷으로 줄인 이유

`omni_reference`에 얼굴 셋을 물리면 드리프트 확률이 급격히 올라간다.
2샷은 1화 컷 6에서 이미 검증된 조건이다(얼굴 유지 ✅).

**잃은 것도 적어둔다** — 태호의 「확신 → 당황 → 붕괴」 3단 리듬,
「태호는 인터넷, 준영은 실전」 대비, 컷 12의 공 다툼. 총 5초쯤 짧아졌다.

## 3. 준영 — 확정 스펙

| 항목 | 확정값 |
|---|---|
| 나이 | **28** (33에서 내림 — 민준과 친구) |
| 배경 | 웜 베이지 심리스 |
| 조명 | 부드러운 웜 확산광 |
| 안경 | **얇은 라운드 와이어 프레임**, 웜 실버 |
| 눈 | 크고 둥근 눈, 눈꼬리 수평 |
| 얼굴 | 짧고 둥근 얼굴, 순하게 웃는 인상 |
| 모자 | **네이비 코튼 볼캡**, 정방향 |
| 상의 | **버건디 와인 코듀로이 오버셔츠** (열어서) + 화이트 티 |
| 하의 | 미드워시 블루 스트레이트 데님 |
| 신발 | 화이트 캔버스 로우탑 |
| 색 | **버건디 + 네이비** |

### 민준과 벌어진 축

| | 민준 | 준영 |
|---|---|---|
| 얼굴 | 갸름한 V라인 미남 | 짧고 둥근 안경 인상 |
| 실루엣 표식 | 없음 | **모자** — 넷 중 유일 |
| 2~5컷 색 | 형광 주황 | 버건디 |
| 6컷~ 색 | 크림 | 버건디 |

⚠️ **버건디로 바꾼 이유.** 원본 시트는 머스터드였는데, 민준이 2~5컷 내내
형광 주황 등산 바람막이를 입고 있어서 같은 색 계열로 묶여 보였다.
컷 2의 웃음은 **「민준 혼자만 이상한 색」**이라서 나온다. 옆 사람도 노랑이면
그게 안 읽힌다.

⚠️ 키가 민준과 비슷하게 크고 마르다. 짧고 다부진 체격이 이상적이었지만
**캡 + 안경 + 색으로 이미 충분히 구분된다.** 체형까지 손대다 얼굴을 잃는 게
더 손해라서 그냥 간다.

## 4. 캐스트 전체 색 설계

| 인물 | 색 |
|---|---|
| 서연 | 크림 아이보리 + 블랙 |
| 민준 (2~5컷) | 형광 주황 |
| 민준 (6컷~) | 크림 |
| 지원 | 데님 블루 |
| 준영 | 버건디 + 네이비 |

주연 둘이 무채색·크림으로 묶이고, 조연 둘만 색을 가진다.
어느 컷에 들어와도 조연이 먼저 눈에 띈다.

## 5. 표정 시트는 만들지 않는다 ★

1화 10컷 전부 **3분할 기본 시트 2개만 걸고** 뽑았고, 「얼굴 유지(레퍼런스 2인
동시) ✅」 검증까지 끝났다(`episode1-hong.md` 0-1).

표정은 **영상 프롬프트 텍스트로 지정**하고, 레퍼런스는 얼굴 동일성만 담당한다.
표정 시트를 레퍼런스로 걸면 오히려 그 표정이 고정돼서 방해가 된다.
서연 표정 4종(`60cd952d…`)도 실제 컷 생성엔 한 번도 걸리지 않았다.

**민준·지원·준영 표정 시트는 만들지 않는다.**
