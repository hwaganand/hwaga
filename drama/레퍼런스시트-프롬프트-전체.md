# 캐릭터 레퍼런스 시트 프롬프트 — 4인 전체

## ⚠️ 생성 순서 (반드시 지킬 것)

실제 인물 사진이 없는 오리지널 캐릭터이므로, 일반적인 순서와 다르다.

```
1. 시트1 생성  (전신정면 / 후면 / 얼굴클로즈업)
        ↓
2. 시트1에서 "얼굴 클로즈업" 부분만 크롭해서 저장
        ↓
3. 그 크롭 이미지를 레퍼런스로 첨부 + 시트2 프롬프트 → 표정 4종 생성
        ↓
4. 같은 크롭 이미지를 레퍼런스로 첨부 + 시트3 프롬프트 → 턴어라운드 생성
        ↓
5. 이후 모든 본편 씬 = 시트1 크롭 + 시트3을 레퍼런스로 첨부
```

**시트1을 레퍼런스 없이 뽑는 건 딱 한 번뿐이다.** 마음에 드는 얼굴이 나올 때까지
시트1만 여러 번 돌리고, 확정된 다음부터는 절대 레퍼런스 없이 생성하지 않는다.

**본부장 한대성 주의**: 본편에서는 얼굴을 거의 안 쓰지만(뒷모습·손짓 위주),
레퍼런스 시트는 반드시 만들어둔다. 뒷모습·실루엣도 체형과 헤어라인이 흔들리면 티가 난다.
