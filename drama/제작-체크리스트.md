# 제작 체크리스트

## 0단계 — 한 번만 하면 되는 것 (약 하루)
- [ ] 캐릭터 4인 레퍼런스 시트 생성 (전신정면 / 표정 4종 / 얼굴 4방향)
      → `/character-reference-sheet` 스킬 사용
- [ ] 레퍼런스 이미지 4장을 **별도 폴더에 고정 보관**. 이후 모든 씬은 이걸 참조로 물린다
- [ ] 배경 3종(회의실·사무실·고깃집) 이미지 각 3앵글씩 = 9장 생성 후 재사용
- [ ] TTS 목소리 5개 확정 (정우 겉/속, 박부장, 본부장, 서진)
- [ ] 자막 템플릿 만들기: 흰색(대사) / 노란색(속마음) 두 프리셋

## 1단계 — 화당 반복 (목표: 화당 2시간)
- [ ] 대본에서 컷 리스트 추출 (이미 대본에 컷 번호 있음)
- [ ] 컷별 이미지 생성 — 레퍼런스 참조 필수
- [ ] 이미지 → 영상 변환 (컷당 3~5초, 움직임 최소로. 과한 카메라 무빙은 AI 티가 난다)
- [ ] 대사 TTS 생성
- [ ] 편집: 컷 붙이기 → 자막 → 효과음 → BGM
- [ ] **무음으로 한 번 재생해보고 이해되는지 확인** ← 이 검수 빼먹지 말 것
- [ ] 9:16 / 1080x1920 / 30fps로 출력

## 2단계 — 업로드
- [ ] 유튜브 숏츠 + 인스타 릴스 동시
- [ ] 제목 = 대본 제목 그대로 (이미 훅으로 설계돼 있음)
- [ ] 해시태그: #직장인 #사내정치 #회사생활 #숏드라마 #직장인공감
- [ ] 고정 댓글로 다음 화 예고 + "여러분 회사에도 박부장 있나요?" 참여 유도

## 5화까지 보고 판단할 지표

| 지표 | 기준 | 미달 시 조치 |
|---|---|---|
| 3초 시청 유지율 | 70% 이상 | 훅 문장 다시. 결과부터 안 던진 것 |
| 완주율 | 50% 이상 | 러닝타임 60초로 축소 |
| 댓글 "우리 회사도" 류 | 전체 댓글 30% 이상 | 상황이 너무 특수함. 더 보편적 소재로 |
| 구독 전환 | 조회 1000당 3명 | 캐릭터 매력 부족. 정우 속마음 비중 늘릴 것 |

**5화까지 위 4개 중 3개 미달이면 콘셉트를 접는다.** 12화까지 끌지 말 것.

## 절대 하지 말 것
1. 실존 회사명 · 업종 · 제품 언급 — 본업 리스크가 그대로 살아난다
2. 특정 인물이 알아볼 만한 실제 사건 각색 — 사내에서 알아본다
3. 사이다 결말 — 공감이 끊긴다
4. 박부장을 순수 악당으로 — 시즌이 안 늘어난다
5. 정치 용어 직접 사용 ("여당", "야당", "탄핵" 등) — 굳이 리스크를 다시 불러들일 이유가 없다
