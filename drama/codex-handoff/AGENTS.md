# 작업 지시: 캐릭터 레퍼런스 시트 생성

너는 이 폴더에서 숏드라마 「차장님은 오늘도 정치 중」의 등장인물 4인에 대한
캐릭터 레퍼런스 이미지를 생성한다. 내장 스킬 `$imagegen`을 사용한다.

---

## 0. 시작 전에 반드시 할 것

1. `$imagegen`의 정확한 인자 형식(출력 경로 지정 방법, 참조 이미지 첨부 방법,
   가로세로 비율 지정 방법)을 **네가 직접 확인하고 그에 맞춰 명령을 구성해라.**
   이 문서에 적힌 예시 명령은 형식이 다를 수 있으니 그대로 믿지 말 것.

2. **참조 이미지 첨부가 되는지 먼저 테스트해라.** 이게 이 작업 전체의 전제 조건이다.
   ```
   1) 아무 인물 얼굴 하나 생성 → test1.png
   2) test1.png를 참조로 첨부해서 "같은 인물의 45도 측면" 생성 → test2.png
   3) 두 이미지가 같은 사람으로 보이는지 사용자에게 확인받는다
   ```
   **여기서 실패하면 그 즉시 작업을 중단하고 사용자에게 보고해라.**
   레퍼런스 첨부가 안 되면 이 작업은 의미가 없다. 억지로 진행하지 마라.
   테스트 파일은 확인 후 삭제한다.

---

## 1. 생성 순서 (인물 1명당)

실제 인물 사진이 없는 오리지널 캐릭터다. 따라서 **시트1이 사진을 대신한다.**

```
[1] prompts/ 에서 해당 인물 파일을 읽는다
        ↓
[2] 시트1 생성 (전신정면 / 후면 / 얼굴클로즈업)
        ↓
[3] ★ 여기서 멈추고 사용자에게 물어본다 ★
    "이 얼굴로 확정할까요?"  →  NO면 [2]로 돌아가 재생성
        ↓
[4] 확정되면, 시트1의 "얼굴 클로즈업" 부분만 크롭해서
    output/<인물폴더>/face-ref.png 로 저장
        ↓
[5] face-ref.png를 참조로 첨부해서 시트2(표정 4종) 생성
        ↓
[6] face-ref.png를 참조로 첨부해서 시트3(턴어라운드) 생성
        ↓
[7] 다음 인물로
```

### 절대 규칙
- **시트1은 참조 없이 생성하는 유일한 이미지다.** 시트2·3은 반드시 face-ref.png를 첨부한다.
- **[3]의 사용자 확인을 건너뛰지 마라.** 얼굴이 확정되기 전에 시트2·3을 만들면
  나중에 전부 다시 만들어야 한다.
- **프롬프트를 임의로 고치지 마라.** `prompts/` 파일의 영어 프롬프트를 **그대로** 쓴다.
  특히 인물 묘사 문장(identity)은 한 글자도 바꾸지 않는다. 이 문장이 얼굴 일관성의 전부다.
  프롬프트에 문제가 있어 보이면 고치지 말고 사용자에게 물어봐라.

## 2. 인물 목록과 파일 경로

| 순서 | 인물 | 프롬프트 파일 | 출력 폴더 | 장수 |
|---|---|---|---|---|
| 1 | 오정우 (차장, 38세, 남) | `prompts/01-오정우.md` | `output/01-jungwoo/` | 3 |
| 2 | 박정만 (부장, 45세, 남) | `prompts/02-박정만.md` | `output/02-jungman/` | 3 |
| 3 | 한대성 (본부장, 52세, 남) | `prompts/03-한대성.md` | `output/03-daesung/` | **4** |
| 4 | 이서진 (신입, 26세, 여) | `prompts/04-이서진.md` | `output/04-seojin/` | 3 |

**주인공인 오정우부터 시작한다.** 가장 많이 등장하는 인물이라 여기서 시간을 더 써도 된다.

### 파일명 규칙
```
output/01-jungwoo/
├── sheet1-body.png          전신정면 / 후면 / 얼굴클로즈업
├── face-ref.png             시트1에서 크롭한 얼굴 (참조용, 이후 전부 여기 물림)
├── sheet2-expressions.png   표정 4종
└── sheet3-turnaround.png    얼굴 4방향
```

한대성만 여기에 `sheet4-backviews.png` 가 추가된다.
(본편에서 얼굴을 거의 안 쓰고 뒷모습·실루엣만 쓰는 캐릭터라 그렇다.
 표정 시트보다 이게 실사용 가치가 높으니 빠뜨리지 마라.)

---

## 3. 이미지 사양

- 시트 이미지는 **가로형**으로 뽑는다 (패널을 가로로 나열하므로)
- 해상도는 `$imagegen`에서 지원하는 범위 내 최대한 높게. 2560x1440 초과는 실험적이라 피한다
- 포맷 PNG

> 참고: 본편 영상은 9:16 세로지만, **레퍼런스 시트는 가로가 맞다.**
> 시트는 얼굴 정보를 담는 자료이지 영상에 그대로 들어가는 소재가 아니다.

---

## 4. 다 끝나면

1. 13장을 사용자에게 보여준다
2. `prompts/00-검수체크리스트.md` 를 읽고 항목별로 점검한 결과를 보고한다
3. 특히 **4인을 나란히 놓았을 때 서로 확실히 구분되는지** 판단해서 알려준다.
   구분이 애매하면 어느 인물의 무엇(헤어스타일/안경/의상 색)을 더 벌려야 할지 제안한다

---

## 5. 하지 말 것

- 사용자 확인 없이 인물 4명을 한 번에 쭉 생성하기 → 시트1 확인 게이트를 반드시 지킨다
- 프롬프트의 인물 묘사 문장 수정 → 얼굴이 흔들린다
- 참조 첨부 없이 시트2·3 생성 → 다른 사람이 나온다
- 레퍼런스 첨부 테스트가 실패했는데 그냥 진행 → 중단하고 보고할 것
