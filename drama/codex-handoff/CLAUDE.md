# 실행 지시서 — Claude Code용

너(Claude Code)가 운전자다. 이미지 생성은 Codex CLI에 시키고, **결과 검수는 네가 직접 한다.**

---

## 파이프라인

```
[1] 너가 prompts/에서 프롬프트를 읽는다
[2] codex-imagegen 스킬로 Codex CLI에 생성을 시킨다
[3] 생성된 PNG를 Read 도구로 직접 열어본다
[4] 네가 눈으로 판단한다 → 통과 / 재생성
[5] 통과하면 다음 시트
```

**핵심은 [3]-[4]다.** 사용자에게 13장을 일일이 대조시키지 마라. 네가 본다.

---

## 이미지 생성 명령

**텍스트 → 이미지 (참조 없음)**
```bash
~/.claude/skills/codex-imagegen/codex-imagegen.sh "프롬프트 전문" /절대경로/output.png
```

**참조 이미지 첨부 (3번째 인자부터, 최대 16장)**
```bash
~/.claude/skills/codex-imagegen/codex-imagegen.sh "프롬프트 전문" /절대경로/output.png /절대경로/face-ref.png
```

성공하면 저장된 PNG의 절대경로가 출력된다.

> Windows에서 실행 중이면 bash 경로 문제가 날 수 있다.
> 실패하면 `bash ~/.claude/skills/codex-imagegen/codex-imagegen.sh ...` 형태로 재시도해라.
> 그래도 안 되면 사용자에게 Git Bash 설치 경로를 물어봐라.

## 작업 순서 (인물 1명당)

### STEP 1 — 시트1 생성 (참조 없음)
`prompts/01-오정우.md`의 시트1 영어 프롬프트를 **그대로** 써서 생성.
→ `output/01-jungwoo/sheet1-body.png`

### STEP 2 — 네가 검수
생성된 PNG를 Read로 열어서 아래를 확인한다:

- [ ] 3패널 구성이 맞는가 (전신정면 / 전신후면 / 얼굴클로즈업)
- [ ] **왼쪽 패널에서 얼굴이 안 보이는가** (보이면 실패)
- [ ] 3패널의 인물이 같은 사람인가
- [ ] 의상이 프롬프트와 일치하는가
- [ ] 인물 묘사(나이·얼굴형·헤어·안경 등)와 실제 이미지가 맞는가
- [ ] **오정우 한정: 너무 잘생기게 나오지 않았는가**
      → 잘생겼으면 실패다. 시청자가 자기를 겹쳐 봐야 하는 주인공이라 평범해야 한다.
         프롬프트에 `plain ordinary face, not handsome` 을 추가해서 재생성한다.

**실패하면 무엇이 왜 틀렸는지 짧게 말하고 재생성한다.**
**같은 시트를 3번 재생성해도 안 되면 멈추고 사용자에게 보고해라.** 쿼터를 태우지 마라.

### STEP 3 — 사용자 승인 (건너뛰지 말 것)
네 검수를 통과하면 사용자에게 이미지를 보여주고 묻는다:
> "이 얼굴로 확정할까요?"

**NO면 STEP 1로 돌아간다. 승인 전에는 절대 STEP 4로 넘어가지 마라.**
시트2·3이 이 얼굴 위에 올라가기 때문에, 여기서 넘어가면 나중에 전부 다시 만들어야 한다.

### STEP 4 — 얼굴 크롭
`sheet1-body.png`의 **오른쪽 1/3**(얼굴 클로즈업 패널)만 잘라서
`output/01-jungwoo/face-ref.png`로 저장한다.

Python이 있으면:
```python
from PIL import Image
im = Image.open("sheet1-body.png")
w, h = im.size
im.crop((int(w*2/3), 0, w, h)).save("face-ref.png")
```
PIL이 없으면 `pip install pillow`. 그것도 안 되면 크롭을 건너뛰고
`sheet1-body.png` 자체를 참조로 쓰되, 프롬프트에
`use the face from the rightmost panel of the reference image` 를 덧붙인다.

### STEP 5 — 시트2 (표정 4종)
`face-ref.png`를 **반드시 참조로 첨부**해서 생성.
→ `output/01-jungwoo/sheet2-expressions.png`

검수 항목:
- [ ] 4패널의 얼굴이 **face-ref와 같은 사람**인가 ← 제일 중요
- [ ] 4패널끼리 서로 같은 사람인가
- [ ] 표정 4종이 **서로 확실히 구분되는가**
- [ ] 헤어스타일·조명·각도가 4패널 동일한가

### STEP 6 — 시트3 (턴어라운드)
`face-ref.png`를 참조로 첨부해서 생성.
→ `output/01-jungwoo/sheet3-turnaround.png`

검수 항목:
- [ ] 4방향(90도 측면 / 45도 / 정면 / 후면)이 맞는가
- [ ] face-ref와 같은 사람인가
- [ ] 후면 패널에서 뒤통수·헤어라인 형태가 식별 가능한가

### STEP 7 — 다음 인물로

## 절대 규칙

1. **프롬프트의 인물 묘사 문장을 수정하지 마라.** 한 글자도. 이 문장이 얼굴 일관성의 전부다.
   (예외: 위 STEP 2의 "잘생김" 보정처럼 이 문서가 명시적으로 허용한 경우만)
2. **시트2·3·4는 참조 첨부 없이 생성하지 마라.** 다른 사람이 나온다.
3. **STEP 3 사용자 승인을 건너뛰지 마라.**
4. **같은 시트 3회 실패 시 멈추고 보고해라.** ChatGPT 구독 쿼터가 소모된다.
5. 4명을 한 번에 쭉 돌리지 마라. 인물별로 승인받고 진행한다.

## 다 끝나면

1. 13장을 사용자에게 보여준다
2. `prompts/00-검수체크리스트.md`를 읽고 항목별 결과를 보고한다
3. **4인을 나란히 놓고 서로 확실히 구분되는지** 네가 판단해서 알려준다.
   애매하면 어느 인물의 무엇(헤어스타일 / 안경 / 의상 색)을 더 벌려야 할지 제안한다
4. `output/` 폴더를 백업하라고 안내한다.
   이후 12화 전체 씬 생성이 이 13장 위에 올라간다

---

## 쿼터 안내

13장 + 재생성분이면 ChatGPT 구독 쿼터를 꽤 쓴다.
**오정우 1명(3~5장)을 먼저 끝내고 사용자에게 진행 여부를 다시 물어라.**
