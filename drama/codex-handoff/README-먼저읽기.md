# 사용법 (3줄)

1. 이 폴더(`codex-handoff/`)를 로컬 PC로 가져간다
2. 그 폴더에서 터미널 열고 `codex` 실행
3. 이렇게 말한다 → **"AGENTS.md 읽고 캐릭터 레퍼런스 생성 시작해"**

끝. 나머지는 Codex가 AGENTS.md 보고 알아서 한다.

---

## 시작 전 확인 2가지

```bash
codex --version
```
- `$imagegen`은 **v0.117.0 이상** 필요
- `gpt-image-2`는 **v0.123.0 이상** 필요
- 낮으면: `npm update -g @openai/codex`

그리고 ChatGPT 계정 로그인이 돼 있어야 한다 (`codex` 실행하면 안내 나옴).

---

## 결과물

`output/` 폴더에 인물별로 떨어진다.

```
output/
├── 01-jungwoo/    오정우 차장  (시트 3장)
├── 02-jungman/    박정만 부장  (시트 3장)
├── 03-daesung/    한대성 본부장 (시트 4장 ← 뒷모습 시트 추가)
└── 04-seojin/     이서진 신입  (시트 3장)
```

총 13장.

---

## 중간에 선생님이 개입해야 하는 지점

**인물마다 시트1이 나오면 Codex가 멈추고 물어봅니다.**
"이 얼굴로 확정할까요?"

여기서 마음에 들 때까지 다시 뽑으세요. **얼굴 확정 전에 다음 단계로 넘어가면 안 됩니다.**
시트2·3은 시트1의 얼굴을 기준으로 만들어지기 때문에, 시트1이 마음에 안 드는데
넘어가면 나중에 12장을 전부 다시 뽑아야 합니다.

---

## 잘 안 될 때

- **레퍼런스 첨부가 안 먹혀서 얼굴이 매번 바뀐다** → Codex 루트를 접고 클로드 쪽 higgs로 오세요.
  이게 이 작업의 성패를 가르는 유일한 기능입니다.
- **`$imagegen` 명령을 못 찾는다** → Codex 버전이 낮습니다. 위 업데이트 명령 실행.
