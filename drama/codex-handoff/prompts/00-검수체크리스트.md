# 검수 체크리스트

## 인물당 (13장 다 뽑은 뒤)
- [ ] 시트1·2·3의 배경이 전부 동일한 무지 회색인가
- [ ] 인물 묘사 문장(identity)이 세 장에 **글자 하나 안 바뀌고** 들어갔는가
- [ ] 의상 색상·재질·소품(사원증 줄 색, 안경테 색, 넥타이 무늬)이 세 장에서 같은가
- [ ] 조명 방향(정면 왼쪽)이 세 장에서 같은가
- [ ] 시트2·3을 **face-ref.png를 첨부해서** 생성했는가
- [ ] 시트2의 표정 4종이 서로 확실히 구분되는가 (특히 박정만 1번 vs 2번)
- [ ] 시트3 후면 패널에서 뒤통수·헤어라인 형태가 식별 가능한가

## 4인 전체
- [ ] 4명을 나란히 놓았을 때 서로 확실히 구분되는가
      → 구분 안 되면 헤어스타일 / 안경 유무 / 의상 색을 더 벌린다
- [ ] 오정우가 너무 잘생기게 나오지 않았는가 (**나오면 다시 뽑는다**)
      → 주인공은 시청자가 자기를 겹쳐 봐야 하는 인물이다. 잘생기면 이입이 끊긴다
- [ ] 한대성 시트4에서 얼굴이 선명하게 보이는 패널이 없는가
- [ ] 전체적으로 채도가 낮고 형광등 느낌이 나는가 (숏폼에서 역으로 눈에 걸리게 하는 장치)
